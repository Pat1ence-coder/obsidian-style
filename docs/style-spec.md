# Apple 风格技术文档样式规范

状态：测试版 0.0.1，尚未发布到真实笔记库。

整体风格：整窗平铺无竖线界面，配低饱和靛蓝界面强调色与暖琥珀阅读强调色。非半透明模式下铺整窗暖白类纸（或素白回退），macOS 半透明窗口下采用单层薄雾防重影真透明；浮层与工作台卡片保持不透明；数字与正文采用等宽节奏。番茄钟不纳入，其余指标改为适合笔记库的口径（见使用指南）。

## 字体和层级

屏幕界面、标题与正文基础变量为系统无衬线字体（`glass.css` 在屏幕模式下切换为等宽字体栈）；代码使用等宽字体。数学渲染器字体不覆盖。默认正文字号 16px，整体大小跟随 Obsidian 文本字号设置。

| 角色 | 屏幕（正文 16px 时） | PDF | 字重 |
| --- | ---: | ---: | ---: |
| 文档标题 | 28px | 22pt | 700 |
| H1 | 24.8px | 18pt | 700 |
| H2 | 21.1px | 16pt | 650 |
| H3 | 18.4px | 14pt | 650 |
| H4 | 16.8px | 12pt | 600 |
| H5 | 16px | 11pt | 600 |
| H6 | 15.2px | 10.5pt | 500 |
| 正文 | 16px | 10.5pt | 400 |
| 表格 | 14px | 9.5pt | 正文 400 / 表头 600 |
| 图注与脚注 | 13px | 9pt | 400 |
| 代码 | 14px | 9.5pt | 400 |

正文行高：基础 1.72（屏幕阅读层 1.8），PDF 1.5。标题行高 1.25–1.4；代码 1.55。粗体只改变字重，不切换字体家族。看板标题 24px，卡片标题 16px（界面不设解释性副标题与底部说明小字），统计数字 28px（明细卡 22px），按钮与徽标 12.5–13.5px，热力图月份 12px。统计数字、徽标、按钮和表格数值使用等宽字体（--ds-font-numeric）。

PDF 中文正文使用宋体，英文使用 Times New Roman；中文标题使用黑体类字体。历史 PDF 验证记录中实际嵌入的字体包括 STSongti-SC、STHeitiSC、TimesNewRomanPS 和 Menlo。MathJax 的部分字形在 PDF 中表现为内嵌 Type3 字形程序。

本规范有意优先于旧的正文 Times New Roman 设置；调整字体家族应修改 tokens.css 或 glass.css，不在各元素规则中单独添加覆盖。

## 色彩与材质

一套低饱和配色，随明暗模式自动切换：低饱和靛蓝作界面控件强调色，暖琥珀作正文阅读强调色，柔和辅色用于统计指标与提示框。

浅色：默认素底 #f5f6f8（开启类纸底色时为暖白 #fbf8ef），卡片纸面 #ffffff（类纸时 #fffdf8），正文 #22252a，标题 #16181d，辅助文字 #555b66，界面主色 rgb(72,86,175)，正文暖琥珀 rgb(180,83,9)。

所有颜色从 tokens.css 中的色调角色派生，以 RGB 三元组存放，用法统一为 rgb(var(--ds-tone-x)) 或 rgba(var(--ds-tone-x), α)：界面主色 --ds-tone-accent（低饱和靛蓝），阅读强调 --ds-tone-amber（暖琥珀），辅色 --ds-tone-1 青、--ds-tone-2 绿、--ds-tone-3 紫、--ds-tone-4 橙、--ds-tone-5 珊瑚红，中性 --ds-tone-neutral。主色悬停、浅底（--ds-accent-soft）、选区、阴影墨色和代码高亮都由这些角色计算得出，其余样式文件不写死色值。浅色块（body）与深色块（body.theme-dark）定义同一组色调属性；构建时插件样式将选择器改写为看板与窗格的根元素。

六个指标色在浅色与深色下都用色觉辨识检查过：橙与绿在红色弱模拟下只达到最低可用间距，因此这两种颜色始终与文字标签同时出现，不单独用颜色区分。

每个指标固定一个色调：贡献分主色、新增字数 4、编辑时长 2、深度专注 3、新建笔记 1、完成任务 5。看板的图标块、徽标、统计圆点、指标切换和热力图色阶都由当前色调混合得到。正文中 Callout 按类型映射到同一组色调，以极淡的渐变底和同色发丝边框呈现；链接、行内代码、高亮、标签、复选框、列表符号与引用竖线统一使用暖琥珀 --ds-tone-amber。

深色：默认底色 #18191c（类纸时 #191816），纸面 #212328（类纸时 #22201d），正文 #e6e8ec，界面主色 rgb(132,146,228)（实心按钮文字 --ds-on-accent 为 #14161b），暖琥珀 rgb(226,163,54)。

浮层与卡片材质：菜单、弹窗、提示框和看板卡片保持不透明，表面为 --ds-frost（微颗粒 + 微光 + 纸面色），配顶部高光（--ds-glass-highlight）、发丝描边（--ds-glass-edge）与三级柔和阴影（--ds-elev-1 至 --ds-elev-3）。凹陷部件（分段控件轨道、搜索框、进度条底槽、代码块）使用 --ds-inset-bg 与内阴影 --ds-inset。全项目样式（含弹窗遮罩）不使用 backdrop-filter，避免半透明窗口下产生合成层重影或黑底。

整窗平铺外壳（shell.css）：左右侧栏、功能区、标签栏、笔记区和状态栏处于同一连续平面，不设悬浮卡片边距、圆角外框或常驻竖向分栏线；分栏拖拽手柄静止透明（--divider-color: transparent），仅悬停或按住时显色；笔记顶部面包屑标题（.view-header-title-container）默认隐藏，悬停页眉时渐显；当前标签为垂直居中的扁平透镜块，底部状态栏无描边。

整窗类纸与半透明玻璃（window-glass.css、window-glass.js）：

1. 暖白类纸回退（未开系统半透明，且插件开启“类纸底色与半透明玻璃”，body.aw-glass:not(.is-translucent)）：在 .app-container 上铺暖白象牙纸底（浅色 #fbf8ef、浓档 #f8f2e2；深色 #191816、浓档 #161512），::before 平铺 200×200 无缝细纤维 SVG 纸纹（淡、标准、浓三档调节纹理与底色），不使用外部图片文件。关闭开关、系统启用“减少透明度”或强制颜色模式时，回退素底（#f5f6f8 / #18191c）。
2. macOS 原生单层防重影真透明（开启 Obsidian“半透明窗口”，主窗口带 body.is-translucent）：清空 body、.app-container、.workspace 及内层标签页与编辑器容器底色，仅在顶层分栏（mod-left-split、mod-right-split、mod-root）和功能区铺一层薄雾 --aw-trans-shell（淡 2%、标准 5%、浓 12%），避免多层半透明底色叠加发闷；mod-root 设 contain: paint，禁用工作区内所有 backdrop-filter、will-change 与布局容器 transition；菜单与弹窗保持不透明纸面，独立弹出窗口（is-popout-window、is-popout-modal）强制 100% 不透明并在 @media print 释放高度锁；插件在 macOS 上通过 Electron nativeTheme.themeSource 同步明暗主题并在卸载时还原，不依赖原生二进制模块。预览页包含 theme-static.html、theme-glass.html、theme-glass-dark.html、theme-translucent.html 与 theme-translucent-dark.html。

控件（controls.css）：功能区图标为 32px、8px 圆角块，悬停呈浅中性底；侧栏视图切换当前项为轻量微底块；文件列表文件夹加粗，去掉文件名前置小圆环，当前笔记采用 13%（深色 18%）低饱和靛蓝浅底（--ds-accent-soft）配深色文字，不加发光胶囊；搜索框为凹陷细线框并预留右侧按钮宽度；主按钮 button.mod-cta 使用低饱和靛蓝实心填充与 --ds-on-accent 文字。

控件、内容块和卡片圆角分别为 8、10、16px。主要间距为 4、8、12、16、24、32px。

## 文档外观细化

glass.css 中的规则全部写在 @media screen 中，打印与 PDF 不受影响。选择器以 body:is(.theme-light,.theme-dark) 开头（深色为 body.theme-dark:not(.theme-light)），比所细化的基础规则多一个类的优先级。浅色与深色块定义相同的一组 --aw-* 变量。

- 窗口底层与笔记区：整窗连续平面，不包外框卡片（见“色彩与材质”）。
- 字体：正文、标题与界面使用等宽字体栈，行高 1.8，字距 .005em。
- 暖琥珀色 --aw-warm（即 --ds-tone-amber，浅色 180,83,9；深色 226,163,54）用于链接、行内代码、高亮、标签与刻度尺圆点。
- 表格：分离边框，10px 圆角细框白底板（--aw-glass-table），表头为微灰底（--ds-inset-bg）；academia 三线表保持不变。
- 实时预览中的表格与阅读视图一致。
  - Obsidian 的表格部件本身带 .markdown-rendered，却位于 .markdown-source-view 之内，所以白色底板用 `:not(.academia, .academia *)` 从祖先上排除 academia。
  - 单元格间距是表格上的变量 --aw-cell-pad（默认 10px 14px，experiment 8px 12px，白色底板 12px 16px）：阅读视图加在单元格上；实时预览的单元格本身无内边距，加在 .table-cell-wrapper 上。
  - 实时预览的 .table-wrapper 默认按内容收缩（fit-content），除未加 wideTable 的 academia 外都设为整行宽，与阅读视图的满宽表格相同。
- 代码块为细边框浅底（--ds-code-bg）；图片为 10px 圆角加 1px 细描边，不加白色外衬底。

看板（workbench-glass.css，仅插件样式）：

- 布局：.aw-bento 为 12 列网格、18px 间距；指标卡与今日进度各占 4 列，活跃趋势 8 列，当天明细 7 列，月度贡献 5 列，其余整行。容器宽度不足 960px 时除指标卡外都占整行，不足 640px 时指标卡也占整行。
- 指标颜色：贡献分 tone-accent、新增字数 tone-4、编辑时长 tone-2、深度专注 tone-3、新建笔记 tone-1、完成任务 tone-5，全局共用这一映射（圆点、热力图分段按钮、指标卡）。
- 指标卡：白色面板，右上角一团该色光斑（径向渐变 95%→0，blur 18px，saturate 1.9），文字始终用正文色而不用指标色；深色模式光斑透明度降到 .55。
- 图表：坐标轴 4 等分且取整（步长为 1、1.5、2、2.5、3、4、5、6、8 乘以 10 的幂）；日柱为指标色 22% 不透明度，7 日均线 2px 实线加 10% 面积；网格线为墨色 7%。月度柱斜纹 135°，本月实色叠白色斜纹，数值胶囊为深色底。
- 主按钮（.aw-primary 与工具栏的「新建笔记」）用主色由上而下加深的渐变、白字，底部加深以保证白字对比度。

标注（.aw-annot）由插件绘制，样式在插件的 annotations.css：标注字号为正文的 0.86 倍，支持六个行外位置（左上、上、右上、左下、下、右下）与双线、虚线、实线、波浪、螺旋五种有机微弧箭头，偏移和预留空间都以标注自身的 em 计；每个标注用一个空的行内块从基线向下（或向上）偏移来撑高所在行（长标注在 13.5em 内折行并按行数增加 --aw-annot-room，行首尾通过 --aw-annot-nudge 防裁切），同一行里上下标注混排也不会重叠；颜色取 tone 色（琥珀为 --ds-tone-amber），目标浅底为标注色 15%；阅读视图支持模糊遮罩自测，打印时自动恢复清晰显示。平滑光标（typing-motion.css）使用纯 2D `transform: translate(x, y)` 90ms 缓出滑移与静止透明呼吸闪烁，不使用 3D 变换、will-change 或 backdrop-filter，在框选、多光标、Vim 模式、减少动态与打印时自动交回原生光标。图解（[!diagram]）在 blocks.css 中定义。图解卡片颜色依次取 tone-3、tone-1、tone-4、tone-2，背景为 9% 色调混入纸面色，18px 方格纸底纹。

## 文档宽度与视图适配

普通文档及 research：820px；experiment：1120px。默认两侧留白为 28px（窄屏 20px）。即使原先“缩减栏宽”设置关闭，本样式也统一控制阅读与编辑容器宽度。窄窗格随容器收缩。

编辑器仅通过共享变量与少量 CM6 规则适配。标题字号由标题行负责，内部 token 不再重复放大。保留 CodeMirror 对缩进、空行和光标位置的原生管理。

历史验证的编辑对照是基于本机 Obsidian CSS 的 DOM 夹具，涵盖字体、字号、行高与 800px 宽度，不等于真实 CM6 编辑、折叠和光标交互验收。

## 表格与插图

普通表格使用细线、浅色表头、等宽数字，尊重 Markdown 的左右/居中对齐。experiment 使用紧凑单元格；academia 保留三线表；wideTable 保留满宽。

figure 语法不变，支持单图、grid-1 到 grid-4，以及「一大多小」的 mosaic-left / mosaic-right（第一张为大图，占满另一列所有行；两列约 3:2；520px 以下竖排）。屏幕上：未指定宽度的单图最宽 720px，所有插图最高 min(72vh, 680px) 并保持比例；多图组每列最宽 420px 并居中，小图保持原始尺寸而不拉伸。指定了像素宽度（如 |640）的图片按作者设置显示，多图组中同样生效，但不超过所在格子。打印与 PDF 不受这些上限影响。图注位于底部，表注（[!table] Callout）位于表格上方，标签加粗并使用标题字体，图注与表注字号为正文的 0.8125 倍（小 0.75、大 0.875；打印 8/9/10pt）。图片保持比例，不强加科学图表圆角。多图按指定列数换行，720px 以下缩为两列，520px 以下竖排。图片内部的字号由原图决定，应为多列打印准备足够清晰的标签。

插图块基础排版样式由文档 style.css 提供；插件 styles.css 负责工作台、素材库、手写标注、滚动刻度尺、插图悬停工具条和各类弹窗。停用插件但保留文档样式时，已有图片仍可以排版。

历史浏览器/PDF 验证材料保留在本地归档。本次整理未运行应用或浏览器，旧截图不能作为当前效果的验证证明。

## 导出规范

默认 A4 纵向、20mm 边距、100% 缩放。print-wide 使用 A4 横向。PDF 始终白底深色文字，移除界面阴影与透明效果。

重复表头；尽量保持表格行完整。普通代码块尽量保持同页，过长代码仍交由分页引擎拆分。长代码行可换行。单图和图注尽量同页，多图组允许跨页。

长公式需要在原文中用 aligned 等结构显式分行；CSS 不尝试自动理解或重写公式。超过一页高度的大图仍需缩小。图号和引用保持作者控制。

历史 PDF 曾使用 Chromium 打印引擎加本机 Obsidian 样式及 MathJax 进行验收。原生 Obsidian 导出与 Better Export PDF 的按钮交互、配置覆盖和第三方插件兼容性，仍需应用内验证。真实笔记库当前的导出缩放未修改。

看板结构：标题栏（品牌标记、视图切换的凹陷轨道、时间与操作按钮）之下，「看板视图」是便当格布局（见上文看板一节），「最近笔记」「月度汇总」「周度复盘」是整宽卡片；页面底色为 --ds-canvas。每张卡片是磨砂白外壳（22px 圆角、--ds-frost、顶部高光、发丝描边、elevation 2），包含统一的头部（38px 白色凸起图标块，图标用指标色；标题与可选同色相徽标，不设副标题）和一块内缩 8px 的白色内容面（15px 圆角、发丝描边、elevation 1），形成「卡片里的卡片」的层次。分段控件为凹陷轨道，选中项是白色凸起胶囊。
