# Apple 风格技术文档样式规范

状态：测试版 0.0.1，尚未发布到真实笔记库。

整体风格参考「Crisp Pulse 知识脉冲看板」：中性石墨灰底、白色内容面、深海蓝主色（原参考图的靛蓝已按用户意见替换）、等宽数字、像素风横幅与统一的模块卡片。番茄钟不纳入，其余指标改为适合笔记库的口径（见使用指南）。

## 字体和层级

屏幕界面、标题与正文使用系统无衬线字体；代码使用系统等宽字体。数学渲染器字体不覆盖。默认正文字号 16px，整体大小跟随 Obsidian 文本字号设置。

| 角色 | 屏幕（正文 16px 时） | PDF | 字重 |
| --- | ---: | ---: | ---: |
| 文档标题 | 32px | 22pt | 600 |
| H1 | 28px | 18pt | 600 |
| H2 | 24px | 16pt | 600 |
| H3 | 20px | 14pt | 600 |
| H4 | 18px | 12pt | 600 |
| H5 | 16px | 11pt | 600 |
| H6 | 16px | 10.5pt | 500 |
| 正文 | 16px | 10.5pt | 400 |
| 表格 | 14px | 9.5pt | 正文 400 / 表头 600 |
| 图注与脚注 | 12px | 9pt | 400 |
| 代码 | 14px | 9.5pt | 400 |

正文行高：屏幕 1.7，PDF 1.5。标题行高 1.25–1.4；代码 1.55。粗体只改变字重，不切换字体家族。看板标题 24px，卡片标题 17px，卡片副标题 13px，统计数字 28px（明细卡 22px），按钮与徽标 12.5–13.5px，热力图月份 12px。统计数字、徽标、按钮和表格数值使用等宽字体（--ds-font-numeric）。文档字号表不变。

PDF 中文正文使用宋体，英文使用 Times New Roman；中文标题使用黑体类字体。历史 PDF 验证记录中实际嵌入的字体包括 STSongti-SC、STHeitiSC、TimesNewRomanPS 和 Menlo。MathJax 的部分字形在 PDF 中表现为内嵌 Type3 字形程序。

本规范有意优先于旧的正文 Times New Roman 设置，以实现屏幕统一无衬线；调整字体家族应修改 tokens.css，不在各元素规则中单独添加覆盖。

## 色彩与材质

配色方案为「海盐石墨」：Apple 式中性石墨灰，配一种呼应横幅天空与海面的深海蓝主色。

浅色：背景 #f0f0f2，纸面 #ffffff，正文 #26272c，标题 #1b1c20，辅助文字 #6b6c74，主色 rgb(47,109,154)。

所有颜色从 tokens.css 中的色调角色派生，以 RGB 三元组存放，用法统一为 rgb(var(--ds-tone-x)) 或 rgba(var(--ds-tone-x), α)：主色 --ds-tone-accent（深海蓝），辅色 --ds-tone-1 潟湖青、--ds-tone-2 苔绿、--ds-tone-3 暮紫、--ds-tone-4 砂金、--ds-tone-5 陶土，中性 --ds-tone-neutral。主色悬停、浅底、选区、阴影墨色和代码高亮都由这些角色计算得出，其余样式文件不写死色值；更换配色只需修改 tokens.css 的配色块。

另有两套可切换的配色：暖砂陶土（body.aw-palette-sand，主色 rgb(182,94,62)）与青瓷（body.aw-palette-celadon，主色 rgb(48,118,108)）。每套配色的浅色块与深色块（body.theme-dark.aw-palette-*）定义完全相同的一组属性，避免选择器优先级让浅色值漏进深色模式；测试会检查这一点。构建时插件样式将这些选择器改写为 body.aw-palette-* .aw-view，因此只装插件时同样生效。

每个指标固定一个色调：贡献分主色、新增字数 1、编辑时长 2、深度专注 3、新建笔记 4、完成任务 5。看板的图标块、徽标、统计圆点、指标切换和热力图色阶都由当前色调混合得到。正文中 Callout 按类型映射到同一组色调，以极淡的渐变底和同色发丝边框呈现；列表符号、表头、行内代码、引用线和分隔线带少量主色调；高亮使用砂金。

深色：背景 #161618，纸面 #1e1e21，正文 #e6e6ea，主色 rgb(116,170,214)；辅色整体提亮。深色实际效果仍待用户验收。

材质：窗口底层是一层环境光（--ds-ambient，天蓝、海雾、浅砂、薄荷的大范围径向渐变）。侧栏、看板卡片外壳、横幅按钮、菜单、命令面板、悬浮预览和通知使用磨砂玻璃（半透明填充、blur 28–30px 与 saturate 175–180%、白色顶部高光、发丝描边和柔和深投影）。笔记纸面与看板内容面保持接近不透明，正文不做模糊。不支持 backdrop-filter、系统开启“减少透明度”或强制配色时退回实色。开启 Obsidian「半透明窗口」时，环境光改为薄纱，让系统原生毛玻璃透出。

控件、内容块和卡片圆角分别为 8、12、18px。主要间距为 4、8、12、16、24、32px。Obsidian 外框（标题栏、功能区、侧栏、标签栏、状态栏）统一使用背景色；主编辑区的每个窗格是 18px 圆角白色卡片，当前标签为白底按钮。标签为等宽小胶囊。

## 文档宽度与视图适配

普通文档及 research：1000px；experiment：1120px。默认两侧留白为 24px。即使原先“缩减栏宽”设置关闭，本样式也统一控制阅读与编辑容器宽度。窄窗格随容器收缩。

编辑器仅通过共享变量与少量 CM6 规则适配。标题字号由标题行负责，内部 token 不再重复放大。保留 CodeMirror 对缩进、空行和光标位置的原生管理。

历史验证的编辑对照是基于本机 Obsidian CSS 的 DOM 夹具，涵盖字体、字号、行高与 800px 宽度，不等于真实 CM6 编辑、折叠和光标交互验收。

## 表格与插图

普通表格使用细线、浅色表头、等宽数字，尊重 Markdown 的左右/居中对齐。experiment 使用紧凑单元格；academia 保留三线表；wideTable 保留满宽。

figure 语法不变，支持单图与 grid-1 到 grid-4。屏幕上：未指定宽度的单图最宽 720px，所有插图最高 min(72vh, 680px) 并保持比例；多图组每列最宽 420px 并居中，小图保持原始尺寸而不拉伸。指定了像素宽度（如 |640）的图片按作者设置显示。打印与 PDF 不受这些上限影响。图注位于底部，图片保持比例，不强加科学图表圆角。多图按指定列数换行，720px 以下缩为两列，520px 以下竖排。图片内部的字号由原图决定，应为多列打印准备足够清晰的标签。

插图样式由文档 style.css 提供；插件 styles.css 只负责工作台和插入窗口。停用插件但保留文档样式时，已有图片仍可以排版。

历史浏览器/PDF 验证材料保留在本地归档。本次整理未运行应用或浏览器，旧截图不能作为当前效果的验证证明。

## 导出规范

默认 A4 纵向、20mm 边距、100% 缩放。print-wide 使用 A4 横向。PDF 始终白底深色文字，移除界面阴影与透明效果。

重复表头；尽量保持表格行完整。普通代码块尽量保持同页，过长代码仍交由分页引擎拆分。长代码行可换行。单图和图注尽量同页，多图组允许跨页。

长公式需要在原文中用 aligned 等结构显式分行；CSS 不尝试自动理解或重写公式。超过一页高度的大图仍需缩小。图号和引用保持作者控制。

历史 PDF 曾使用 Chromium 打印引擎加本机 Obsidian 样式及 MathJax 进行验收。原生 Obsidian 导出与 Better Export PDF 的按钮交互、配置覆盖和第三方插件兼容性，仍需应用内验证。真实笔记库当前的导出缩放未修改。

看板结构：像素风横幅（标题、视图切换、筛选按钮，底部一条渐变细线）之下是单列模块卡片，页面底层是环境光与一层模糊放大的横幅。每张卡片为玻璃外壳（22px 圆角、白色高光、发丝描边、柔和深投影），包含统一的头部（42px 色相图标块、标题、以「·」分隔的副标题、同色相徽标）和一块内缩 8px 的磨砂内容面（15px 圆角）。统计数字横排，以细竖线分隔；列表行为直边细线。内容面不再单独模糊，以免叠加两层滤镜。

横幅由 scripts/pixelate-header.py 从 src/assets/coast-header.png 生成（420×140、32 色、4×4 有序抖动），CSS 以 image-rendering: pixelated 放大并向背景色渐隐；深色模式下压暗。
