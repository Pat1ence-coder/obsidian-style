# Apple 风格技术文档样式规范

状态：测试版 0.0.1，尚未发布到真实笔记库。

整体风格：纯白、干净的数据工作台。近白底色上是不透明的白色磨砂面板，以发丝描边和分级阴影区分层次；一套亮蓝主色配橙、绿点缀；等宽数字与正文。番茄钟不纳入，其余指标改为适合笔记库的口径（见使用指南）。

## 字体和层级

屏幕界面、标题与正文使用系统无衬线字体；代码使用系统等宽字体。数学渲染器字体不覆盖。默认正文字号 16px，整体大小跟随 Obsidian 文本字号设置。

| 角色 | 屏幕（正文 16px 时） | PDF | 字重 |
| --- | ---: | ---: | ---: |
| 文档标题 | 32px | 22pt | 600 |
| H1 | 28px | 18pt | 600 |
| H2 | 24px | 16pt | 600 |
| H3 | 20px | 14pt | 600 |
| H4 | 18px | 12pt | 600 |
| H5 | 16px | 11pt | 600 |
| H6 | 16px | 10.5pt | 500 |
| 正文 | 16px | 10.5pt | 400 |
| 表格 | 14px | 9.5pt | 正文 400 / 表头 600 |
| 图注与脚注 | 12px | 9pt | 400 |
| 代码 | 14px | 9.5pt | 400 |

正文行高：屏幕 1.7，PDF 1.5。标题行高 1.25–1.4；代码 1.55。粗体只改变字重，不切换字体家族。看板标题 24px，卡片标题 17px，卡片副标题 13px，统计数字 28px（明细卡 22px），按钮与徽标 12.5–13.5px，热力图月份 12px。统计数字、徽标、按钮和表格数值使用等宽字体（--ds-font-numeric）。文档字号表不变。

PDF 中文正文使用宋体，英文使用 Times New Roman；中文标题使用黑体类字体。历史 PDF 验证记录中实际嵌入的字体包括 STSongti-SC、STHeitiSC、TimesNewRomanPS 和 Menlo。MathJax 的部分字形在 PDF 中表现为内嵌 Type3 字形程序。

本规范有意优先于旧的正文 Times New Roman 设置，以实现屏幕统一无衬线；调整字体家族应修改 tokens.css，不在各元素规则中单独添加覆盖。

## 色彩与材质

只有一套纯净配色：白色面板、浅灰蓝底色，主色亮蓝，橙色与绿色作点缀。

浅色：背景 #f3f5f9，纸面 #ffffff，正文 #1f2633，标题 #111827，辅助文字 #667085，主色 rgb(52,128,246)。

所有颜色从 tokens.css 中的色调角色派生，以 RGB 三元组存放，用法统一为 rgb(var(--ds-tone-x)) 或 rgba(var(--ds-tone-x), α)：主色 --ds-tone-accent（亮蓝），辅色 --ds-tone-1 青、--ds-tone-2 绿、--ds-tone-3 紫、--ds-tone-4 橙、--ds-tone-5 珊瑚红，中性 --ds-tone-neutral。主色悬停、浅底、选区、阴影墨色和代码高亮都由这些角色计算得出，其余样式文件不写死色值。浅色块（body）与深色块（body.theme-dark）定义同一组色调属性；构建时插件样式将选择器改写为看板与窗格的根元素。

六个指标色在浅色与深色下都用色觉辨识检查过：橙与绿在红色弱模拟下只达到最低可用间距，因此这两种颜色始终与文字标签同时出现，不单独用颜色区分。

每个指标固定一个色调：贡献分主色、新增字数 1、编辑时长 2、深度专注 3、新建笔记 4、完成任务 5。看板的图标块、徽标、统计圆点、指标切换和热力图色阶都由当前色调混合得到。正文中 Callout 按类型映射到同一组色调，以极淡的渐变底和同色发丝边框呈现；列表符号、表头、行内代码、引用线和分隔线带少量主色调；高亮使用砂金。

深色：背景 #111318，纸面 #1a1d24，正文 #e4e7ec，主色 rgb(76,142,247)；辅色亮度略降以保持与深色背景的对比。深色实际效果仍待用户验收。

材质：所有面板都不透明，不透出下层内容。「磨砂感」来自五样东西：极淡的颗粒纹理（--ds-grain）、自上而下极轻的暗化（--ds-glass-sheen）、顶部白色高光（--ds-glass-highlight）、发丝描边（--ds-glass-edge）和多层柔和阴影；三者合成的表面为 --ds-frost（颗粒 + 微光 + 纸面白）。阴影分三级：--ds-elev-1 用于按钮、标签、内层面板，--ds-elev-2 用于看板卡片、表格、图片卡，--ds-elev-3 用于侧栏面板、笔记卡片、菜单和弹窗。凹陷的部件（分段控件轨道、搜索框、进度条底槽、代码块）使用 --ds-inset-bg 与内阴影 --ds-inset。浅色与深色各定义一套同名值。除弹窗背后的遮罩外不使用 backdrop-filter。

窗口底层是纯色近白（--ds-bg，浅色 #f6f7f9，深色 #0f1013），不再有壁纸、薄纱和环境光渐变；看板窗格内的底色为 --ds-canvas（#fbfbfc），比纯白略深一丝，让白色卡片的边缘可辨。左右侧栏的内容区是悬浮面板：外边距 8px、圆角 16px、--ds-frost 填充、elevation 3。笔记卡片同为 --ds-frost，内部的 --background-primary 设为透明，使编辑器和阅读视图显示卡片本身的磨砂表面。当前标签是白色胶囊（elevation 1），状态栏为磨砂小面板。

窗口毛玻璃（window-glass.css）：由插件设置「窗口毛玻璃」开启（默认开），插件给 body 加 aw-glass 与 aw-glass-fog-{light,normal,strong}，不传任何图片。主题在 .app-container 的 ::before 上铺纸面 --ds-glass-paper-texture：一块 1400px、可无缝平铺的 SVG 分形噪声（feTurbulence fractalNoise，baseFrequency .0055，5 个八度），用 feColorMatrix 只取一个通道作为明暗云纹，同时写入红、绿、蓝三个通道，所以纸面是纯灰、不带色相；浅色平均约 0.85 灰，深色平均约 0.12 灰。::after 上铺细颗粒 --ds-glass-grain（180px 噪声，alpha .06）和雾 --ds-glass-fog：浅色为白 15%、30%、50%，深色为 rgb(18,18,18) 15%、30%、50%。笔记区额外叠白 45%（--ds-glass-wash），只留一条 45% 白的发丝边；侧栏面板、笔记卡片、状态栏和看板画布的底色、描边、阴影全部去掉。纸面和玻璃各层（雾、笔记区、分隔线、输入框、悬停）都是 R=G=B 的中性色，由测试约束（纸面的颜色矩阵三行必须相同）；不使用图片文件或渐变。窗口本身不透明，不使用 Obsidian 的「半透明窗口」（is-translucent），因为它在 macOS 上透不出桌面并产生重影。系统「减少透明度」或强制颜色模式下不画纸面与雾。预览页 theme-glass.html、theme-glass-dark.html 与 Obsidian 中所见一致。

控件（controls.css）：选中即蓝色实心、白色内容——侧栏视图切换的当前项（10px 圆角方块）、文件列表的当前笔记（10px 圆角胶囊，带 --ds-select-glow 蓝色光晕）、主按钮 button.mod-cta；其余控件静止时不着色，悬停时为 10% 主色浅底（--ds-hover-tile）。功能区图标为 36px、11px 圆角方块；笔记前的圆环 8px、1.5px 描边；树形引导线 1.5px、中性色 22%。普通按钮白底，以 1px 发丝描边和极轻投影表现（--input-shadow）。

控件、内容块和卡片圆角分别为 8、12、18px。主要间距为 4、8、12、16、24、32px。Obsidian 外框（标题栏、功能区、侧栏、标签栏、状态栏）统一使用背景色；侧栏为悬浮玻璃面板（见上），主编辑区的每个窗格是 18px 圆角白色卡片，当前标签为玻璃按钮。标签为等宽小胶囊。

## 文档外观细化

glass.css 中的规则全部写在 @media screen 中，打印与 PDF 不受影响。选择器以 body:is(.theme-light,.theme-dark) 开头（深色为 body.theme-dark:not(.theme-light)），比所细化的基础规则多一个类的优先级。浅色与深色块定义相同的一组 --aw-* 变量。

- 窗口底层与笔记卡片：不透明磨砂（见「色彩与材质」）。
- 笔记区：根窗格卡片为 --ds-frost，内部原本使用 --background-primary 的元素透明，显示卡片的磨砂表面。
- 字体：正文、标题与界面使用等宽字体栈，行高 1.85，字距 .01em。
- 暖橙色 --aw-warm（浅色 204,110,48；深色 238,154,98）用于行内代码、高亮与刻度尺圆点；链接与标签等界面强调用主色亮蓝。
- 表格：分离边框，14px 圆角白色底板（elevation 1），表头为凹陷灰底（--ds-inset-bg）；academia 三线表保持不变。
- 实时预览中的表格与阅读视图一致。
  - Obsidian 的表格部件本身带 .markdown-rendered，却位于 .markdown-source-view 之内，所以白色底板用 `:not(.academia, .academia *)` 从祖先上排除 academia。
  - 单元格间距是表格上的变量 --aw-cell-pad（默认 10px 14px，experiment 8px 12px，白色底板 12px 16px）：阅读视图加在单元格上；实时预览的单元格本身无内边距，加在 .table-cell-wrapper 上。
  - 实时预览的 .table-wrapper 默认按内容收缩（fit-content），除未加 wideTable 的 academia 外都设为整行宽，与阅读视图的满宽表格相同。
- 代码块为凹陷底（--ds-code-bg 与内阴影）；图片放在 12px 内边距、14px 圆角的白色卡片上（elevation 2）。

看板（workbench-glass.css，仅插件样式）：

- 布局：.aw-bento 为 12 列网格、18px 间距；指标卡与今日进度各占 4 列，活跃趋势 8 列，当天明细 7 列，月度贡献 5 列，其余整行。容器宽度不足 960px 时除指标卡外都占整行，不足 640px 时指标卡也占整行。
- 指标颜色：贡献分 tone-accent、新增字数 tone-4、编辑时长 tone-2、深度专注 tone-3、新建笔记 tone-1、完成任务 tone-5，全局共用这一映射（圆点、热力图分段按钮、指标卡）。
- 指标卡：白色面板，右上角一团该色光斑（径向渐变 95%→0，blur 18px，saturate 1.9），文字始终用正文色而不用指标色；深色模式光斑透明度降到 .55。
- 图表：坐标轴 4 等分且取整（步长为 1、1.5、2、2.5、3、4、5、6、8 乘以 10 的幂）；日柱为指标色 22% 不透明度，7 日均线 2px 实线加 10% 面积；网格线为墨色 7%。月度柱斜纹 135°，本月实色叠白色斜纹，数值胶囊为深色底。
- 主按钮（.aw-primary 与工具栏的「新建笔记」）用主色由上而下加深的渐变、白字，底部加深以保证白字对比度。

标注（.aw-annot）由插件绘制，样式在插件的 annotations.css：标注字号为正文的 0.86 倍，箭头、偏移和预留空间都以标注自身的 em 计；六个行外位置用一个空的行内块从基线向下（或向上）偏移来撑高所在行，同一行里上下标注混排也不会重叠；颜色取 tone 色（琥珀为新增的 --ds-tone-amber），目标浅底为标注色 15%；打印时照常显示。图解（[!diagram]）在 blocks.css 中定义。图解卡片颜色依次取 tone-3、tone-1、tone-4、tone-2，背景为 9% 色调混入纸面色，18px 方格纸底纹。

## 文档宽度与视图适配

普通文档及 research：1000px；experiment：1120px。默认两侧留白为 24px。即使原先“缩减栏宽”设置关闭，本样式也统一控制阅读与编辑容器宽度。窄窗格随容器收缩。

编辑器仅通过共享变量与少量 CM6 规则适配。标题字号由标题行负责，内部 token 不再重复放大。保留 CodeMirror 对缩进、空行和光标位置的原生管理。

历史验证的编辑对照是基于本机 Obsidian CSS 的 DOM 夹具，涵盖字体、字号、行高与 800px 宽度，不等于真实 CM6 编辑、折叠和光标交互验收。

## 表格与插图

普通表格使用细线、浅色表头、等宽数字，尊重 Markdown 的左右/居中对齐。experiment 使用紧凑单元格；academia 保留三线表；wideTable 保留满宽。

figure 语法不变，支持单图、grid-1 到 grid-4，以及「一大多小」的 mosaic-left / mosaic-right（第一张为大图，占满另一列所有行；两列约 3:2；520px 以下竖排）。屏幕上：未指定宽度的单图最宽 720px，所有插图最高 min(72vh, 680px) 并保持比例；多图组每列最宽 420px 并居中，小图保持原始尺寸而不拉伸。指定了像素宽度（如 |640）的图片按作者设置显示，多图组中同样生效，但不超过所在格子。打印与 PDF 不受这些上限影响。图注位于底部，表注（[!table] Callout）位于表格上方，标签加粗并使用标题字体，图注与表注字号为正文的 0.8125 倍（小 0.75、大 0.875；打印 8/9/10pt）。图片保持比例，不强加科学图表圆角。多图按指定列数换行，720px 以下缩为两列，520px 以下竖排。图片内部的字号由原图决定，应为多列打印准备足够清晰的标签。

插图样式由文档 style.css 提供；插件 styles.css 只负责工作台和插入窗口。停用插件但保留文档样式时，已有图片仍可以排版。

历史浏览器/PDF 验证材料保留在本地归档。本次整理未运行应用或浏览器，旧截图不能作为当前效果的验证证明。

## 导出规范

默认 A4 纵向、20mm 边距、100% 缩放。print-wide 使用 A4 横向。PDF 始终白底深色文字，移除界面阴影与透明效果。

重复表头；尽量保持表格行完整。普通代码块尽量保持同页，过长代码仍交由分页引擎拆分。长代码行可换行。单图和图注尽量同页，多图组允许跨页。

长公式需要在原文中用 aligned 等结构显式分行；CSS 不尝试自动理解或重写公式。超过一页高度的大图仍需缩小。图号和引用保持作者控制。

历史 PDF 曾使用 Chromium 打印引擎加本机 Obsidian 样式及 MathJax 进行验收。原生 Obsidian 导出与 Better Export PDF 的按钮交互、配置覆盖和第三方插件兼容性，仍需应用内验证。真实笔记库当前的导出缩放未修改。

看板结构：标题栏（品牌标记、视图切换的凹陷轨道、筛选与操作按钮）之下，「看板视图」是便当格布局（见上文看板一节），「最近笔记」「月度汇总」是整宽卡片；页面底色为 --ds-canvas。每张卡片是磨砂白外壳（22px 圆角、--ds-frost、顶部高光、发丝描边、elevation 2），包含统一的头部（42px 白色凸起图标块，图标用指标色；标题、以「·」分隔的副标题、同色相徽标）和一块内缩 8px 的白色内容面（15px 圆角、发丝描边、elevation 1），形成「卡片里的卡片」的层次。分段控件为凹陷轨道，选中项是白色凸起胶囊。
