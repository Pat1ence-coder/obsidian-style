# 算法工作台

Obsidian 桌面插件，提供「写作工作台」主页：指标卡、今日进度、活跃趋势、年度热力图、日期明细、最近编辑和月度汇总；另有「素材库」，集中浏览笔记库里的图片。不依赖其他社区插件，不访问网络，仅在用户执行新建、插图或导出命令时创建、修改文件。

## 使用

首次安装可将 dist/algorithm-workbench 文件夹放到笔记库的 .obsidian/plugins/ 下。更新已有安装时不要删除或整目录替换，优先使用scripts/install.py：它只更新 main.js、manifest.json、styles.css，不写入 data.json，也不会复制源码目录里的同名统计文件。

安全更新步骤：

1. 在工作目录执行 npm run build。
2. 执行 python3 -B scripts/install.py --target /path/to/vault/.obsidian/plugins/algorithm-workbench 预览目标位置，此步骤不写文件。
3. 在 Obsidian 中关闭「算法工作台」，等待待保存统计完成。
4. 执行 python3 -B scripts/install.py --target /path/to/vault/.obsidian/plugins/algorithm-workbench --apply。
5. 重新启用插件。

更新前会将旧运行文件和 data.json 备份到 .obsidian/algorithm-workbench-backups/时间戳/。备份独立于插件目录；更新中途失败会尝试回退已替换的运行文件。插件仍启用时脚本会停止更新，避免运行期间覆盖文件。现有统计和设置始终保留在安装目录的 data.json 中，源码修改和构建不会清空它们。

安装源、目标目录、配置文件和备份路径必须使用实体目录与普通文件，不能包含符号链接（包括悬空链接）。检测到链接时，预览和实际安装都会停止；请使用真实笔记库内的实体插件目录。

安装后，在 Obsidian「设置 → 第三方插件」启用「算法工作台」。若未出现在列表中，重新加载 Obsidian。点击左侧工作台图标，或运行命令「算法工作台：打开写作工作台」。

默认启动时在新标签页打开看板。顶部三个视图：

- 看板视图：便当格布局的指标卡、今日进度、活跃趋势、年度活跃热力图、所选日期明细、月度贡献和最近 5 篇笔记（详见下文「外观」）。
- 最近笔记：按修改时间列出最近编辑的笔记，篇数可在设置中调整，默认 8 篇。
- 月度汇总：最近 12 个月各项指标的表格。

「时间」按钮切换统计范围（最近 30、90、180、365 天），影响概览数字和热力图分级；热力图始终显示完整 53 周，范围外的日期淡化。热力图上方可切换指标，点击日期在明细卡片中查看当天数字和贡献的笔记。强度按所选范围内个人活跃日的排名分为四档，不使用固定阈值。

「导出全量 CSV」在笔记库根目录写入「写作工作台-日期.csv」，包含每个有记录日期的各项指标，重名时自动加序号，不覆盖已有文件。Obsidian 默认不在文件列表显示 CSV，可在系统文件管理器中打开。

可在插件设置中暂停统计、调整列表数量和排除文件夹；默认排除 Templates 和 templates。

## 配色与控件

只有一套纯净配色，随 Obsidian 的明暗模式自动切换：白色面板、浅灰蓝底色，主色为亮蓝，橙色与绿色作点缀。早期版本的海盐石墨、暖砂陶土、青瓷三套配色和「配色」切换已移除；旧设置会被自动忽略。

侧栏与按钮：

- 左侧图标栏是圆角方块，悬停时变为浅蓝底、蓝色图标。
- 侧栏顶部的视图切换（文件、搜索、书签）中，当前打开的一项是蓝色实心方块、白色图标。
- 文件列表里文件夹为粗体，每篇笔记前有一个小圆环，当前笔记是蓝色实心胶囊、白色文字，子文件夹带树形引导线。
- 主按钮（如对话框的确认按钮、看板的「新建笔记」）为蓝色实心并带柔和光晕；其他按钮为白底细描边。

窗口外框（关闭窗口毛玻璃或未启用插件时）：底色是近白的纯色，没有壁纸和渐变。左右侧栏和笔记都是不透明的白色磨砂面板（极淡的颗粒纹理、顶部高光、发丝描边、柔和阴影），与窗口边缘留出间隙并带圆角；当前标签是白色胶囊，状态栏是磨砂小面板。面板不透出下层内容，正文清晰。

## 外观

只有一种外观（早期的「悬浮卡片」风格与「界面风格」切换已移除，旧设置会被自动忽略）：

- 文档：正文与标题使用等宽字体，行内代码和高亮为暖橙色，链接为蓝色；表格是圆角白色底板，图片放在白色圆角卡片上；笔记右侧显示滚动刻度尺。只影响屏幕显示，打印与 PDF 始终使用同一套学术排版。
- 看板：便当格（bento）布局，从上到下是：
  - 三张指标卡：累计贡献分（附活跃天数）、新增字数（附当前连续，徽标是最长连续天数）、编辑时长（附深度专注），统计范围随「时间」按钮变化。卡片一角是该指标颜色的光斑：贡献分蓝、字数橙、时长绿。
  - 今日进度：今天的新增字数和编辑时长，与时间范围内此前活跃日的日均值比较（进度条满格即达到日均），下方是今天的专注分钟、新建笔记和完成任务，以及「新建笔记」按钮。
  - 活跃趋势：最近 30 天（时间范围为 30 天时）或最近 90 天（其余范围）。浅色细柱是每日贡献分，曲线是 7 日均值；鼠标移到图上显示当天的数值，徽标是期间峰值。
  - 年度活跃热力图与当天明细。
  - 月度贡献：最近 6 个月的贡献分，斜纹柱，本月为实色；悬停显示活跃天数。
  - 继续编辑：最近修改的笔记。

  这些模块随编辑实时更新，不需要手动刷新。「最近笔记」「月度汇总」两个视图是整宽卡片。

窗口毛玻璃：插件设置「外观 → 窗口毛玻璃」默认开启，不需要任何图片。主题在整个窗口后面铺一张「纸」：浅灰的纸面上有柔和的明暗云纹，不带颜色，再盖一层中性的白雾和细颗粒（深色模式为深灰纸面和暗雾），看起来像隔着磨砂玻璃看哑光纸。侧栏、标签栏、笔记和看板连成一片玻璃，笔记区略亮，不再有单独的白色面板；菜单、弹窗、当前标签、插图、表格、代码块和看板卡片仍是白色卡片，浮在玻璃上。「毛玻璃雾的浓度」可选淡、标准、浓：越浓越亮越素净，越淡纸纹越明显。关闭开关、只启用文档样式而未启用插件，或系统设置了「减少透明度」时，保持白色外观。不需要也不建议打开 Obsidian 自带的「半透明窗口」，它在 macOS 上会产生重影。

不需要也不建议打开 Obsidian 自带的「设置 → 外观 → 半透明窗口」：在 macOS 上它透不出桌面，还会让文字留下重影（Electron 的已知问题，样式无法修复）。如果已经打开，关闭后用 Cmd+Q 完全退出再重新打开 Obsidian。

等宽字体按顺序使用本机已安装的 Maple Mono NF CN、Maple Mono、Sarasa Mono SC、霞鹜文楷等宽、JetBrains Mono，都没有时退回系统等宽字体加苹方。想要中英文都等宽，建议安装 Maple Mono NF CN。

滚动刻度尺：笔记右侧的细刻度和圆点显示阅读位置（0.00–1.00），点击或拖动刻度尺可跳转；它取代了该笔记的竖向滚动条。可在「外观 → 滚动刻度尺」中关闭。

刻度尺旁的标题：刻度尺左侧的页边列出笔记的一到三级标题，每个标题按它在全文中的位置排列，用一小段横线连到刻度尺上。圆点所在的那一节（圆点上方最近的标题）文字加深、横线变长；点击标题，圆点移到它的刻度上，标题也就停在与圆点同高的位置。标题太密时，级别高的优先显示，同级的先出现者优先。页边放不下标题时（窗口较窄或打开了侧栏），平时只显示刻度尺，指针移到刻度尺上或拖动时，标题以白色小卡片浮在正文上。可在「外观 → 刻度尺旁显示标题」中关闭。

角落装饰图：在「外观 → 角落装饰图」中填写笔记库内一张图片的路径（如 assets/mascot.png），它显示在窗口右下角，不响应点击、不打印。图片被重命名时设置自动跟随，删除后不再显示。

## 标注与图解

标注：在高亮后面紧跟花括号写标注，阅读视图和实时预览中，标注用手写体写在高亮文字的外侧，由一条斜向的双虚线箭头指向目标文字，目标文字带一层同色浅底：

```markdown
着色器之间通过 ==varyings=={标注一下} 传递数据。
密钥 ==never be reused=={这是标注|左下}。
模型学会了不写 ==verbose code=={冗长代码|右下 橙 虚线}。
```

竖线后面是可选设置，用空格分隔，顺序随意，都可以省略：

- 位置：右下（默认）、下、左下、右上、上、左上，或箭头 ↘ ↓ ↙ ↗ ↑ ↖。这六个位置的标注写在行外，这一行会自动加高，不会压住上下行的文字。段落换行时，不超过 24 个字的目标不会从中间断开，放不下就整体移到下一行，标注始终跟着它；更长的目标可以断开，这时标注按目标首尾所在的范围定位，可能偏离。左下、左上的标注在目标恰好位于行首时会伸进左侧页边，窗口很窄时可能被裁掉一部分。示例笔记「05-标注与图解」演示全部写法和多行段落里的效果。「右」「左」（或 → ←）则把标注直接排在目标文字的后面或前面。
- 颜色：蓝（默认）、中性、琥珀、橙、绿、红、紫、彩虹，或 #rgb / #rrggbb 自定义颜色。
- 线条：双线（默认）、虚线。
- 无高亮：目标文字不加浅底，适合本身已有底色的文字。

竖线后面只要有一个词不是上面的设置，整段都当作标注内容，所以标注里也可以写竖线。标注内容不超过 80 个字（设置不计入），花括号要紧贴高亮的右侧 ==，且不换行。旧笔记里的 {批注} 写法照常有效，按默认的右下方显示。

更方便的方式是在编辑器里选中一段文字，右键选「添加标注」，在对话框里填写标注内容，选择位置（3×3 方向盘）、颜色、是否高亮目标和线条，插件会写好上面的语法。光标放在已有标注上右键，可以「编辑标注」或「删除标注」（删除只去掉标注，保留高亮）。

光标移到标注上时显示原文，可直接修改。标注打印和导出 PDF 时照常显示。手写体依次使用 macOS 自带的手札体、翩翩体、行楷，其次是霞鹜文楷和楷体；也可以在「外观 → 标注字体」中填写本机已安装的字体。停用插件后，花括号按原文显示。

图解：用 [!diagram] Callout 画一组卡片，标题是左上角的小号大写标签，列表每一项是一张浅色卡片（加粗为卡片标题，行内代码为右下角的小标签），列表之后的段落是居中的脚注：

```markdown
> [!diagram] Knowledge / four states
> - **原始输入** 文章 · 想法 · 记录 `raw`
> - **参考资料** 来源 · 证据 · 资料 `source`
> - **综合认识** 对照 · 判断 · 提炼 `knowledge`
> - **场景输出** 文章 · 方案 · 答案 `output`
>
> 按需要来回使用，也可以停留在任何一种状态
```

写成 [!diagram|rows] 时卡片纵向排成整行。卡片颜色按顺序在紫、青、橙、绿之间循环。图解样式由文档 style.css 提供。

## 在选中文件夹中新建笔记和文件夹

默认启用「跟随选中文件夹新建」。左键点击文件树中的文件夹后，使用原生新建笔记命令（通常为 ⌘N / Ctrl+N），或点击文件列表顶部的「新建笔记」「新建文件夹」按钮，都会在选定目录内创建。点击文件时跟随其父文件夹。工作台也会出现「新建笔记」按钮，悬停显示目标目录。

新文件命名为「未命名.md」，新文件夹命名为「未命名文件夹」，重名时自动增加序号，保留已有内容。新文件夹创建后显示在文件树中并请求进入原生重命名状态，方便立即填写名称。插件记住当前会话的选择，不跨重启保留。未选择目录、功能关闭或目标目录已删除时，原生命令按 Obsidian 自身设置运行。右键文件夹的原生菜单保持不变。

可在「算法工作台 → 文件与新建」中关闭该功能，也可以通过命令面板执行「在选中文件夹中新建笔记」或「在选中文件夹中新建文件夹」。模块不改写系统快捷键配置。

原生新建命令的目标目录没有公开扩展接口，因此模块封装了 file-explorer:new-file 和 file-explorer:new-folder 命令的 callback，并核对了本机安装版本的实现。禁用功能会直接转交原命令，卸载时恢复原 callback。未来 Obsidian 版本若改变内部命令接口，可能需要适配；独立的新建命令及工作台按钮仍使用 Vault 公开 API。文件列表顶部按钮通过限定在文件浏览器内的图标选择器识别，不依赖界面语言，右键菜单不受拦截。其他插件若也封装同一命令，或未来版本更改工具栏图标与文件树状态结构，需在应用内验证兼容性。

## 粘贴 Markdown 源码

从 VS Code 等代码编辑器复制 Markdown 时，剪贴板里除了原文，还有一份每行一个 `<div>` 的 HTML。Obsidian 默认开启「设置 → 编辑器 → 自动转换 HTML」，会把这份 HTML 转成 Markdown，每一行都变成单独一段，表格因此被空行拆散，无法显示。

插件默认开启「文件与新建 → 粘贴 Markdown 源码保持原样」。以下两种情况按原文粘贴，换行统一为 `\n`：

- 剪贴板的 HTML 来自代码编辑器（外层标着 `white-space: pre`）；
- 剪贴板文字里有 Markdown 表格（表头行加 `| --- |` 分隔行）。

其他粘贴照旧由 Obsidian 处理：网页上的富文本仍转成 Markdown，图片仍按附件保存。需要临时按原文粘贴任何内容时，可用 ⌘⇧V（Windows 为 Ctrl+Shift+V）。

## 截图命名

默认启用「图片与附件 → 截图按笔记命名」。新粘贴的默认截图使用当前笔记名，例如：

```text
Attention 推导-截图-20261012-152031-045.png
```

时间使用设备本地时区，末尾包含毫秒；同一毫秒连续插入会添加序号。保存目录仍遵循附件设置，路径生成、重名处理、图片写入和链接插入继续由 Obsidian 原生逻辑完成。命名时替换文件名中的特殊字符，较长的笔记名截取前 32 个 Unicode 码点。

只识别 Obsidian 默认的 Pasted image 名称与 PNG/JPEG/WebP 图片，不批量重命名旧附件，不改动已有自定义名称。之后重命名笔记不会自动改名已有截图。截图仍可通过图片链接正常引用。

该功能封装了本机版本原生粘贴使用的附件路径解析方法；这是内部兼容接口，未来 Obsidian 更新可能需要适配。关闭功能时沿用原名称，卸载插件时恢复原方法。界面中的开关可以随时关闭此功能。

## 插图排版

在正在编辑的 Markdown 笔记中打开命令面板，执行「算法工作台：插入排版图片」。可从电脑导入图片、搜索库内已有图片，或先选中一个现有图片链接再运行命令。选择「单张图片」或「多图 · 1–4 列」布局后插入。多图不限总张数，按列数自动换行，共用一条图注。可以从电脑一次多选导入，也可以连续添加库内图片，并使用上移、下移、移除按钮整理顺序。单图继续支持像素宽度与对齐设置。

导入遵循 Obsidian「文件与链接」中的附件目录设置，使用原生附件路径生成接口处理重名，不自动移动或改写已有图片。普通图片粘贴与拖放保持原生行为；粘贴后可选中其链接，再运行命令转换。

生成的语法只有两行：

```markdown
> [!figure|center] 图 1 · 训练损失曲线
> ![[附件/loss.png|640]]
```

center 可改为 left 或 right。640 是像素宽度，去掉图片链接里的 |640 则使用原图宽度。图注显示在图片下方，图片不拉伸比例，超出窄页面时缩小。也支持 Obsidian 原生 Markdown 图片链接格式。

多图用 grid-N 指定列数，后面每行放一张图片，总张数不限。例如 5 张图片按 3 列排列：

```markdown
> [!figure|grid-3] 图 1 · 不同方法的结果对比
> ![[方法A.png]]
> ![[方法B.png]]
> ![[方法C.png]]
> ![[方法D.png]]
> ![[方法E.png]]
```

支持 grid-1、grid-2、grid-3、grid-4。数字表示列数，不是图片数量。

「一大多小」布局：一列放一张大图，另一列竖排其余图片。第一张图片是大图；mosaic-left 大图在左，mosaic-right 大图在右。三张图片时就是一大两小：

```markdown
> [!figure|mosaic-left] 图 2 · 整体结构与两处细节
> ![[整体结构.png]]
> ![[细节A.png]]
> ![[细节B.png]]
```

大图列与小图列宽度约为 3:2；可用宽度不超过 520px 时全部竖排。插图命令的「布局」里也可直接选择「大图在左 / 大图在右」。

最后一行不足时保留已有图片，不补空图、不截断。各列等宽，图片保持比例、不裁切。可用宽度不超过 720px 时，三列和四列缩为两列；不超过 520px 时全部竖排。打印保留指定列数，多图组允许跨页。

可以先选中多行图片链接，再运行插图命令，窗口会识别整组选图。图号手动填写，不做自动编号、浮动定位或复杂交叉引用。内容仍是原生 Callout 与图片链接，没有额外 HTML。

### 在笔记中调整插图

鼠标悬停在已插入的插图上，右上角出现工具条（编辑视图与阅读视图均可）：

- 调整大小（单图和多图组的每一张都可以）：拖动图片右下角内侧的圆点，旁边实时显示宽度；松开后写回图片链接里的像素宽度（按 10px 取整，最小 40px）。单图靠近文字列宽的 1/4、1/3、1/2、2/3、3/4 或整列时会吸附，并显示该宽度的轮廓。多图组中的图片最大不超过所在格子。
- 单图对齐：工具条上的左对齐、居中、右对齐按钮；或拖动图片左上角的手柄，屏幕上会标出「左对齐 / 居中 / 右对齐」三个位置，靠近哪个就显示哪个位置的虚线轮廓，松开即对齐。图片已占满整列时会提示先缩小。
- 多图组：工具条上是 1–4 列和「大图在左 / 大图在右」按钮；拖动图片左上角的手柄，一张缩小的图片跟随鼠标，离得最近的位置显示虚线轮廓和「放到这里」，松开后图片移到该位置（拖到大图位置即成为大图）。离开插图太远则不移动。
- 拖动过程中按 Esc 取消。

所有修改直接改写 Markdown（对齐、列数写回 [!figure|…]，宽度写回 |640，顺序即图片行的顺序），因此打印和 PDF 与屏幕一致。不支持把图片拖到任意坐标：任意定位在导出时无法保持。编辑视图中的修改可以撤销；阅读视图中会先确认笔记没有变化再写入。工具条可在插件设置「图片与附件 → 插图编辑工具」中关闭。

### 图注与表注

按学术惯例，图注在图下方、表注在表上方，标签（「图 1」「表 2-3」「Figure 4」「Table 5」）加粗，图注比正文小一号。表格需要表注时这样写：

```markdown
> [!table] 表 1 不同配置的检索效果
> | 方法 | MRR@10 |
> | --- | ---: |
> | Baseline | 0.372 |
```

字号可在插件设置「外观 → 图注与表注字号」中选择小、标准、大；打印时分别为 8、9、10pt。只启用文档样式而未启用插件时使用标准字号，标签不加粗。

窗口打开后若原笔记发生变化，会拒绝覆盖旧位置，请重新运行命令。多图会先检查选图列表；所有图片准备好后才一次性插入完整 Markdown。中途导入失败时，已导入的附件保留，重试会复用它们。取消时不插入文本；如果导入文件已写入完成才取消，附件保留，可下次从库中选择。本项目的插图样式由文档 style.css 提供；只要该样式启用，即使停用插件，已有 figure 块仍保持排版。

## 素材库

点击左侧的图片图标，或运行命令「算法工作台：打开素材库」，素材库在右侧边栏打开。它列出笔记库里的所有图片（png、jpg、jpeg、gif、webp、avif、svg、bmp），新增、改名、删除图片后自动更新，不修改图片文件。

- 布局：图片以白色卡片按瀑布流排列，每张卡片放进当前最短的一列。卡片左上角是像素尺寸（如 1964×2740），GIF、SVG 另有类型角标；下方是文件名、格式和文件大小。特别长的截图只显示上半部分，特别宽的图片裁去两侧。滚动到底部时自动加载下一批。
- 窄面板与宽面板：侧边栏宽度不足 560px 时，范围（全部、待整理、已评星、文件夹、标签）是一个下拉框；把面板拖宽（或拖到主区域）后，左侧出现目录树和标签列表，卡片按宽度排成多列。右上角「小 / 中 / 大」调整卡片大小。
- 范围：
  - 「全部素材」：所有图片。
  - 「待整理」：没有被任何笔记嵌入或链接的图片。角落装饰图使用的图片也算已用。
  - 「已评星」：评过星的图片。
  - 资源目录：选中一个文件夹时，包括它下面的子文件夹。顶层文件夹的图标按主题色轮流着色。
  - 标签：点击标签只看带这个标签的图片。
- 搜索与筛选：
  - 搜索框按文件名（含扩展名）、文件夹和标签查找，多个词需要同时匹配。
  - 筛选项有类型（图片、GIF、SVG）、比例（横图、竖图、方图）和星级（几星以上、未评星）。
  - 排序可选最近修改、最早修改、名称（中文按拼音）和文件最大。
  - 按比例筛选时，还没读过尺寸的图片会在后台读取，读完陆续出现。
- 星级：指针移到卡片上会出现五颗星，点击评分，再点同一颗星取消。评过星的卡片一直显示星级。
- 打开与插入：
  - 点击卡片，在新标签页打开图片。
  - 把卡片拖进笔记，由 Obsidian 写入嵌入链接。
  - 右键「插入到当前笔记」，在最近编辑的笔记光标处插入 `![[图片]]`（按 Obsidian 的链接格式设置）。这一项要求那篇笔记处在编辑模式。
  - 右键「复制嵌入链接」，复制同样的链接。
- 标签：右键「编辑标签…」，用空格或逗号分隔，每张最多 12 个，已有标签可点选。标签只保存在插件数据里，不写进图片或笔记。
- 引用：右键菜单列出引用这张图片的笔记，点击在新标签页打开。Obsidian 自己和其他插件的文件操作（例如在文件列表中显示）也会出现在这个菜单里。
- 筛选条件随面板保存，重启 Obsidian 后保持。

## 统计口径

- 按设备本地日期记录，汉字、字母、数字、标点和 emoji 按 Unicode 码点计数，空白不计入。组合 emoji 可能包含多个码点。
- 包含 Markdown、YAML、公式、代码与粘贴内容，不等同于实际创作字数。
- 统计每篇笔记当天长度超过已记录最高值的增量。例如从 100 字增至 120 字计 20；删回 100 再恢复到 120 不重复计数。同长度改写不增加统计。
- 新的一天以本次编辑前的长度为基线，既有笔记不会被当作当天新写内容。
- 仅记录 CodeMirror 标记为用户输入、删除、撤销、重做或移动的编辑事务。同步、导入和其他未标记事务只调整基线，不增加统计。部分插件自动插入的内容也可能不计入。
- 第一次启用之前的每日写作历史无法还原，启用前日期显示为无记录。
- 编辑时长：有用户编辑的分钟数，加上两次编辑之间不超过 5 分钟的停顿。超过 5 分钟没有输入即开始新的时段。
- 深度专注：一个连续时段累计达到 25 分钟后，整个时段计入专注，之后每分钟继续计入。时段只保存在内存中，重启 Obsidian 会重新开始。
- 新建笔记：Obsidian 完成加载后新建的 Markdown 文件，排除目录不计。同步或其他插件创建的笔记也会计入。
- 完成任务：编辑器中新勾选的任务（- [x]），只检查本次修改涉及的行；与字数相同，每篇笔记当天按最高值计，反复勾选只算一次。粘贴或拖入的已勾选列表不计。阅读视图中的勾选会经由编辑器同步，没有打开编辑器时可能不计入。
- 贡献分 = 新增字数 ÷ 100 + 编辑分钟 ÷ 10 + 专注分钟 ÷ 10 + 新建笔记 × 2 + 完成任务。贡献分不单独存储，随时由每日数字计算。
- 旧版（v1）统计文件只含字数；升级后自动迁移，原有字数历史保留，其余四项从升级当天开始记录。
- 用于单台设备，不合并多设备统计。不应让多个设备同时写入此插件的 data.json。

## 存储与恢复

安装目录中的 data.json 保存设置、每日总数、笔记路径及计数基线，以及素材库里各图片的星级和标签（按图片路径），不保存笔记正文。编辑后约 750 毫秒触发保存；同时只保留一个正在写入的快照，慢速写入期间的更新合并为最新状态，不逐次排队。正常禁用时也尝试保存。强制退出或断电可能丢失最后一次尚未保存的增量。

重命名笔记、图片或文件夹会迁移统计路径以及图片的星级和标签；删除图片或文件夹时，对应的星级和标签一并删除。删除笔记保留历史贡献，但历史条目不再可点击。读取到损坏或未知版本的数据时停止加载，不自动覆盖原数据。保存失败会提示并重试。备份笔记库时可一并备份 data.json。

## 内存与刷新

首次遇到文档时扫描一次全文，后续按编辑变更片段更新字符数。计数缓存使用 WeakMap，不强行保留已关闭编辑器的旧文档；涉及拆分 Unicode 代理对的少数编辑会回退到全文计数以保证准确性。

工作台关闭后不安排刷新；隐藏时跳过绘制，重新激活时更新。普通统计变化只更新数字、日历色块及变化的列表，切换日期范围或设置时才重建页面。关闭视图时释放缓存的 DOM 引用。

跨天清理旧计数基线，保留每日历史统计。历史数据随使用正常增长，不自动删除用户记录。自动化测试包含慢速写入时 10,000 次保存请求合并、增量计数和隐藏视图检查；不等同于 Obsidian 实际堆内存分析。

## 开发

源码使用 JavaScript 和 Obsidian 提供的 CodeMirror 6 API，无需安装 npm 依赖。Node.js 18 或以上：

```sh
npm test
```

所有功能都安装在同一个 algorithm-workbench 插件目录内，源码按职责拆分：

- src/main.js：插件入口、设置和统计生命周期。
- src/styles/：共享变量、文档组件、编辑器、工作台和打印样式。
- src/core.js：字符计数、日历及统计数据逻辑。
- src/features/workbench.js：工作台页面。
- src/features/dashboard-data.js：看板的图表数据（趋势序列、坐标轴刻度、今日对比、月度柱）。
- src/features/folder-notes.js：文件夹选择、新建命令及监听清理。
- src/features/figures.js：插图选择、导入与设置窗口。
- src/features/figure-format.js：两行插图 Markdown 的生成和校验。
- src/features/figure-edit.js：已有插图块的宽度、对齐、列数和顺序改写（纯文本行操作）。
- src/features/figure-tools.js：插图悬停工具条、拖动调整大小与位置（含轮廓提示）和图注标签。
- src/features/annotation-format.js、annotations.js：标注语法解析与生成、阅读视图与实时预览中的渲染、右键菜单与标注对话框。
- src/features/scroll-ruler.js：滚动刻度尺与刻度尺旁的标题。
- src/features/library-data.js、library.js：素材库。前者是图片清单、筛选、排序、目录树、瀑布流分列和星级与标签的保存（不依赖 Obsidian）；后者是索引、视图、右键菜单和标签对话框。
- src/features/decor.js：角落装饰图。
- src/features/screenshot-names.js：默认截图名称与原生附件路径接入。

后续子功能继续放入 src/features，通过入口统一注册，不需要额外安装其他插件目录。scripts/build.js 自动打包本地模块，输出到 dist/algorithm-workbench/；部署文件只有 main.js、manifest.json、styles.css。不要直接把 src/main.js 用作插件入口，它尚未打包。

测试涵盖计数、跨天、重启、重命名、排除目录、日历边界、异常数据、插件生命周期及异步保存。Obsidian 实际加载、编辑器事件和视觉效果仍需在应用中验收。

## 卸载

在设置中禁用插件即可停止记录。移除插件目录会同时移除其中的统计；如需保留，请先备份 data.json。卸载不会删除任何笔记。
