### 提示框的六种颜色

提示框按用途分成六组颜色，同一组的别名颜色相同。

> [!abstract] 摘要 · 紫
> 同组：summary、tldr、example。

> [!info] 信息 · 青
> 同组：todo。

> [!tip] 提示 · 绿
> 同组：hint、important、success、check、done。

> [!warning] 注意 · 橙
> 同组：question、help、faq、caution、attention。

> [!danger] 危险 · 红
> 同组：failure、fail、missing、error、bug。

> [!quote] 引用 · 中性
> 同组：cite。

> [!example]+ 可折叠的提示框（默认展开）
> 标题后加 `+` 默认展开、加 `-` 默认折叠。导出 PDF 时折叠的内容也会展开。

## 需要在 Obsidian 里操作的

以下功能由插件「算法工作台」提供，需要启用插件（设置 → 第三方插件），主题片段也要启用（设置 → 外观 → CSS 代码片段）。

| 功能 | 在哪里 | 怎么试 |
| :--- | :--- | :--- |
| 写作工作台 | 左侧功能区的笔与纸图标、底部状态栏进度徽章，或命令「打开写作工作台」 | 切换看板视图、最近笔记、月度汇总、周度复盘；点「复制本周周报」生成 Markdown 周报；在设置里填「每日目标字数」观察看板与状态栏达标进度 |
| 素材库 | 左侧功能区的图片图标，或命令「打开素材库」，在右侧边栏打开 | 「待整理」里能看到 `assets/curve-5.svg`；点卡片打开大图预览（`←` `→` 切图、`1–5` 评星、点色卡复制 `#hex`）；试按颜色筛选与「漫游」；在面板内按 `⌘V` 粘贴截图或拖入图片归档 |
| 插入排版图片 | 在编辑中的笔记里，命令「插入排版图片」 | 从电脑导入或搜索库内图片，选单张或 1–4 列、大图在左 / 右 |
| 插图工具 | 「03-多图验收」，鼠标移到插图上 | 拖右下角圆点改宽度，拖左上角手柄改对齐或换位置；拖动中按 Esc 取消 |
| 手写标注与自测 | 编辑模式下选中文字右键「添加标注」；命令「切换标注自测遮罩」「查看与复制当前笔记标注」 | 在弹窗中实时预览位置、颜色和五种线条；阅读视图单击标注模糊自测、双击编辑或删除；打开标注汇总搜索并点击跳行 |
| 滚动刻度尺与标题 | 打开「01-排版样板」，看正文右侧 | 点击或拖动刻度尺平滑跳转；标题密集或窄窗口时把指针移到刻度尺上浮出目录；重开长笔记点刻度尺上的蓝色小菱形（或命令「跳到上次阅读位置」）返回 |
| 在选中文件夹中新建 | 文件树 | 先点一下某个文件夹，再按 ⌘N（Windows 为 Ctrl+N），新笔记建在这个文件夹里 |
| 粘贴 Markdown 源码 | 设置 → 算法工作台 → 文件与新建 | 在 VS Code 里打开「02-实验宽表.md」，复制表格，粘贴到任意笔记，表格保持完整，不会被空行拆开 |
| 截图按笔记命名 | 任意笔记 | 粘贴一张截图，文件名是「笔记名-截图-日期-时间」 |
| 类纸底色与半透明玻璃 | 设置 → 算法工作台 → 外观 → 类纸底色与半透明玻璃 | 未开系统半透明时铺暖白类纸底色，开启 macOS「半透明窗口」时切换单层防重影玻璃；「纹理与玻璃雾度」选淡、标准、浓 |
| 平滑光标 | 设置 → 算法工作台 → 外观 → 平滑光标 | 在任意笔记编辑视图连续打字、回车换行或中文输入法上屏，观察光标平滑滑移与静止呼吸闪烁；框选、多光标、Vim 或减少动态时自动交回原生光标 |
| 图注与表注字号 | 设置 → 外观 → 图注与表注字号 | 选小、标准、大，对照「04-学术三线表」 |
| 标注字体 | 设置 → 外观 → 标注字体 | 填本机已安装的手写字体名，例如 LXGW WenKai |
| 角落装饰图 | 设置 → 外观 → 角落装饰图 | 填一张库内图片的路径，例如 `assets/compact-1.svg`，它显示在窗口右下角 |
| 打印与 PDF | 文件菜单「导出为 PDF」 | 「02-实验宽表」用横向纸张；「01-排版样板」的折叠内容会展开；标注照常打印 |

[^1]: 脚注显示在文末，字号与图注相同、颜色较淡。
