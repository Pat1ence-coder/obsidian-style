### 提示框的六种颜色

提示框按用途分成六组颜色，同一组的别名颜色相同。

> [!abstract] 摘要 · 紫
> 同组：summary、tldr、example。

> [!info] 信息 · 青
> 同组：todo。

> [!tip] 提示 · 绿
> 同组：hint、important、success、check、done。

> [!warning] 注意 · 橙
> 同组：question、help、faq、caution、attention。

> [!danger] 危险 · 红
> 同组：failure、fail、missing、error、bug。

> [!quote] 引用 · 中性
> 同组：cite。

> [!example]+ 可折叠的提示框（默认展开）
> 标题后加 `+` 默认展开、加 `-` 默认折叠。导出 PDF 时折叠的内容也会展开。

## 需要在 Obsidian 里操作的

以下功能由插件「算法工作台」提供，需要启用插件（设置 → 第三方插件），主题片段也要启用（设置 → 外观 → CSS 代码片段）。

| 功能 | 在哪里 | 怎么试 |
| :--- | :--- | :--- |
| 写作工作台 | 左侧功能区的笔与纸图标，或命令「打开写作工作台」 | 切换看板视图、最近笔记、月度汇总；点「时间」换统计范围；点热力图上的日期看当天明细 |
| 素材库 | 左侧功能区的图片图标，或命令「打开素材库」，在右侧边栏打开 | 「待整理」里能看到 `assets/curve-5.svg`，它故意没被任何笔记引用；指针移到卡片上评星，右键「编辑标签…」，把卡片拖进正在编辑的笔记 |
| 插入排版图片 | 在编辑中的笔记里，命令「插入排版图片」 | 从电脑导入或搜索库内图片，选单张或 1–4 列、大图在左 / 右 |
| 插图工具 | 「03-多图验收」，鼠标移到插图上 | 拖右下角圆点改宽度，拖左上角手柄改对齐或换位置；拖动中按 Esc 取消 |
| 添加标注 | 编辑模式下选中一段文字，右键「添加标注」 | 在对话框里选位置、颜色、线条和是否高亮；在已有标注上右键可「编辑标注」「删除标注」 |
| 滚动刻度尺与标题 | 打开「01-排版样板」，看正文右侧 | 点击或拖动刻度尺跳转；点页边的标题，圆点移到该标题；窗口窄时把指针移到刻度尺上，标题浮出 |
| 在选中文件夹中新建 | 文件树 | 先点一下某个文件夹，再按 ⌘N（Windows 为 Ctrl+N），新笔记建在这个文件夹里 |
| 截图按笔记命名 | 任意笔记 | 粘贴一张截图，文件名是「笔记名-截图-日期-时间」 |
| 窗口毛玻璃 | 设置 → 算法工作台 → 外观 → 窗口毛玻璃 | 开关类纸的磨砂玻璃；「毛玻璃雾的浓度」选淡、标准、浓 |
| 图注与表注字号 | 设置 → 外观 → 图注与表注字号 | 选小、标准、大，对照「04-学术三线表」 |
| 标注字体 | 设置 → 外观 → 标注字体 | 填本机已安装的手写字体名，例如 LXGW WenKai |
| 角落装饰图 | 设置 → 外观 → 角落装饰图 | 填一张库内图片的路径，例如 `assets/compact-1.svg`，它显示在窗口右下角 |
| 打印与 PDF | 文件菜单「导出为 PDF」 | 「02-实验宽表」用横向纸张；「01-排版样板」的折叠内容会展开；标注照常打印 |

[^1]: 脚注显示在文末，字号与图注相同、颜色较淡。
